# 내 PC의 윈도우 작업 스케줄러로 실행한다

처음에는 GitHub Actions에서 돌렸다([ADR 0002](0002-github-actions-실행과-bot-state-브랜치.md)). 그런데 2026-11-09 두 번 실행해 두 번 모두 청년일경험 포털 연결이 시간 초과(`URLError: timed out`)로 실패했다. 같은 코드가 국내 PC에서는 1초 안에 정상 동작했고, 오류가 SSL 오류가 아니라 응답 없음이었다. 그래서 포털이 해외 IP(GitHub Actions 서버) 접속을 막는다고 판단했다. 국내 IP에서 돌아야 하므로 내 PC의 작업 스케줄러로 매일 09:00·18:00에 실행한다. 보낸 공고 기록과 실행 로그는 PC의 `state/` 폴더에 두고 GitHub에는 올리지 않는다.

## Considered Options

- 국내 리전 클라우드 서버(예: AWS 서울 리전): 24시간 돌 수 있지만 계정·비용·설정 시간이 들어 지원 마감(2026-11-14) 전에는 하지 않는다. 다음 단계 후보.
- GitHub self-hosted runner를 내 PC에 설치: 공개 저장소에서는 남이 보낸 코드가 내 PC에서 실행될 위험이 있어 GitHub도 권장하지 않는다.

## Consequences

- PC가 꺼져 있거나 잠들어 있으면 그 시각에는 돌지 않는다. "놓친 실행은 가능한 빨리 실행" 설정을 켜 두어서 PC를 켜면 바로 한 번 돈다.
- GitHub Actions는 코드를 올릴 때마다 테스트만 자동으로 돌린다.
