# 잡코리아·원티드는 자동 수집하지 않는다

평소 공고를 보는 사이트는 청년일경험 포털, 잡코리아, 사람인, 원티드 네 곳이지만, 출처는 청년일경험 포털·잡알리오·사람인으로 정했다. 원티드는 이용약관에서 봇·스크래퍼로 게시물을 모으는 것을 명시적으로 금지한다. 잡코리아는 공식 API를 공공기관·학교에만 주고, 약관이 무단 복제를 금지하며, 해외 IP 접속을 차단한다고 밝힌다(이 봇은 해외 IP인 GitHub Actions에서 돈다). 두 사이트 모두 내부 주소로 기술적으로는 쉽게 가져올 수 있지만, 공개 저장소에 약관 위반 코드를 두지 않기 위해 뺐다.

## Considered Options

- 네 곳 모두 웹페이지에서 긁어오기: 약관 위반이고 차단될 위험이 커서 기각.
- 공식 API 신청 후 추가: 이번 일정(2026-11-11까지 구현) 안에 승인되기 어렵다. 승인이 나면 출처를 하나 더 붙이는 방식으로 추가할 수 있다.

## Consequences

- 원티드·잡코리아에만 올라오는 공고는 알림이 오지 않는다. 이 두 곳은 직접 확인해야 한다.
- 조사 근거(2026-11-09): 원티드 개인회원 이용약관 제19조 ⑦, 잡코리아 API 안내(jobkorea.co.kr/service/api), 잡코리아 개인회원 약관 제18조, 잡코리아 보안정책 차단 안내.
